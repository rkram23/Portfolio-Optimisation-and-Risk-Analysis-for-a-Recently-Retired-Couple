# Optimal Investment Strategy for Conflicting Client Preferences

## Overview

This project analyses real stock market data and applies statistical methods and portfolio optimisation to develop an investment strategy for a recently retired couple, John and Mary, who have different risk and return preferences.

## Objectives

- Analyse stock returns, volatility, and confidence intervals.
- Conduct statistical tests, including normality tests and Hotelling’s T² test.
- Examine correlations, dependence, and diversification benefits.
- Construct John’s minimum-variance portfolio and Mary’s growth portfolio.
- Optimise a household portfolio that balances both investors’ preferences.
- Validate portfolio performance using out-of-sample data.
- Evaluate the reliability and limitations of portfolio optimisation.

## Methodology

1. **Data preparation:** Obtain, clean, and align historical stock market data.
2. **Statistical analysis:** Calculate returns, volatility, confidence intervals, and correlations.
3. **Portfolio construction:** Develop individual portfolios based on each investor’s preferences.
4. **Optimisation:** Construct a household portfolio using risk-return objectives and investment constraints.
5. **Validation:** Compare estimated performance with out-of-sample results.
6. **Recommendation:** Evaluate the trade-offs between return, risk, and diversification.

## Key Findings

The optimised household portfolio balances John’s preference for lower risk with Mary’s preference for higher growth. Out-of-sample validation showed that volatility estimates were more consistent than return estimates, highlighting the uncertainty involved in portfolio optimisation.

## Tools and Technologies

## Disclaimer

This project is for academic and educational purposes only. The findings are based on historical data and should not be interpreted as a guarantee of future investment performance or as personalised financial advice.
